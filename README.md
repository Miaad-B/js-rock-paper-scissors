# **Rock Paper Scissors – JavaScript Game**

This learning project is a **Rock–Paper–Scissors game** built with **vanilla JavaScript**.  
It includes score tracking, autoplay mode, keyboard shortcuts, and persistent storage using **localStorage**.

---

## **Features**

- **Play against the computer** using Rock, Paper, or Scissors  
- **Scoreboard** that tracks **Wins, Losses, and Ties**  
- Score is **saved automatically** using `localStorage`  
- **Autoplay mode** that plays a round every second  
- **Reset score** button with a confirmation message  
- **Keyboard shortcuts** for fast gameplay:
  - `r` → Rock  
  - `p` → Paper  
  - `s` → Scissors  
  - `a` → Toggle Autoplay  
  - `Backspace` → Reset Score  
- **Dynamic UI updates** showing both player and computer moves with icons  

---

## ** Technologies Used**

- **HTML5**  
- **CSS3**  
- **JavaScript (DOM manipulation, events, localStorage)**  

---

## **Learning Focus**

This project helped me practice:

- Updating the DOM dynamically  
- Handling click and keyboard events  
- Using `setInterval` for autoplay functionality  
- Persisting data with `localStorage`  
- Writing clean, reusable JavaScript functions  
- Structuring a small interactive game  

---

## **How It Works**

- The game randomly selects a computer move using `Math.random()`  
- The result is calculated based on standard Rock–Paper–Scissors rules  
- The score is updated and saved to `localStorage`  
- The UI updates to show:
  - The result  
  - The moves played  
  - The updated score
